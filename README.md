# 🌌 NexusAI - Dark Mode Intelligent Companion

A sleek, multifunctional AI chatbot built with Next.js 14, designed to assist with coding, learning, and daily emotional support. Features a dynamic dark UI that adapts to your current mode.

## ✨ Features
- **🤖 Multi-Persona AI**: Switch between Coder, Tutor, and Listener modes instantly.
- **⚡ Real-time Streaming**: Powered by Groq API for lightning-fast responses.
- **🎨 Dynamic UI**: Glassmorphism design with smooth Framer Motion animations.
- **💻 Code Highlighting**: Built-in syntax highlighting for programming tasks.
- **📱 Mobile First**: Fully responsive and optimized for Termux/Mobile deployment.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **AI Provider**: Groq (Llama 3 70b)
- **Animations**: Framer Motion
- **Deployment**: Vercel
